F&O API Studio

A Postman-style API tester for Dynamics 365 Finance & Operations — OData, JSON and SOAP custom services — that lives in Chrome's side panel.

No analytics, no telemetry Data stays on your device No remote code Minimal permissions

Documents

  • Privacy policy — what the extension accesses, where it goes, and what it never collects.
  • Security design — threat model, secret handling and the extension's trust boundaries.
  • Permission justifications — why each manifest permission is requested.
  • Source code — open repository with issues, changelog and store-submission docs.

What it does

  • Build and send OData requests with metadata-assisted entity and key pickers, $filter/$select/$expand helpers, and paging through @odata.nextLink.
  • Call JSON and SOAP custom services with a WSDL-driven operation picker and a generated envelope you can still edit.
  • Sends anything else over raw HTTP, with declarative assertions on the response — no scripting engine, no eval.
  • Keeps environments, {{variables}}, collections and history across sessions, in your browser profile only.
  • Signs in via session cookie, Entra interactive (PKCE), client credentials or a manual bearer token — secrets stay in the background process.
